BELLMONT — Landing Page com catálogo real

Abra index.html no navegador.
Para publicar, mantenha a pasta assets/ junto do arquivo index.html.

Conteúdo: 20 streetwear + 22 perfumes + 5 IMPÉRIO FIT.
As fotos e os preços foram fornecidos pelo usuário.
Não há checkout nem estoque conectado. Os links encaminham uma consulta ao WhatsApp.
A linha IMPÉRIO FIT consulta um WhatsApp separado e não entra na sacola BELLMONT.
As imagens foram convertidas para WebP para reduzir o tamanho do site.

A landing page é uma prévia independente do site BELLMONT original.

Configuração antes da publicação:
- Defina a URL oficial da loja em SITE_CONFIG.storeUrl, no index.html. Enquanto estiver vazia, os links “Loja completa” exibem uma mensagem informativa e não apontam para endereço fictício.
- O projeto Cloudflare Pages permanece estático (Framework: None, Build command: exit 0, Output directory: .).
- Pendência externa: reconectar o projeto Cloudflare Pages à conta/repositório GitHub. Isso não é um erro do HTML e exige acesso à configuração remota.
- Termos de Uso e Política de Privacidade aguardam documentos oficiais aplicáveis a esta landing page.

Rodapé: crédito "Desenvolvido por AS" abre o portfólio do desenvolvedor em uma nova aba.
